Private LLM

On-premise, privacy-preserving large language model inference — no data leaves the university network.

On-Premise Deployment Zero External Calls University of Cyprus Network
01
What Is Private LLM?
On-Premise Locally Hosted DMSL Infrastructure

The Private LLM module provides access to large language models deployed entirely within the University of Cyprus network. All inference runs on university-managed hardware — no queries, responses, or metadata are sent to external cloud services.

Research context: This interface supports confidential research workflows where data sovereignty is critical.
02
Capabilities
Inference

Local Model Hosting

Open-source LLMs deployed on university GPU infrastructure with no dependency on cloud APIs.

Privacy

Data Sovereignty

All conversations remain within the university network. No telemetry, no external logging, no third-party access.

Integration

ChromaDB + RAG

Integrates with ChromaDB vector store for retrieval-augmented generation over private document collections.

Access

UCY Network Access

Available to University of Cyprus researchers and staff connected to the UCY network or VPN.
